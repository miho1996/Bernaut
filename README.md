# Bernaut

AI-аналитик листингов лаунчпада **Pons** (Robinhood Chain). Bernaut собирает все токены с Pons, оценивает каждый по 12 метрикам и даёт вердикт: **Заходить / Ждать / Пропустить**.

## Что внутри

`index.html` — весь фронтенд в одном файле (HTML + CSS + JS, без сборки):

- **AI Picks** — токены с лучшей оценкой.
- **Все листинги** — табы Market cap / New / Active / Near graduation / Graduated, фильтр по вердикту, поиск, вид списком или сеткой.
- **Страница токена** — 12 метрик, разбор оценки по каждой, AI-обзор: плюсы, риски, вход, стоп, цель, размер позиции.

### Метрики

Ликвидность / MC, концентрация топ-10 холдеров, доля дева, снайперы, число холдеров, давление покупок, объём / MC, прогресс бондинг-кривой, возраст, соцсети, история дева (rug), лок / burn LP.

Итоговая оценка — взвешенная сумма (0–100). От 66 и выше — «Заходить», 46–65 — «Ждать», ниже 46 — «Пропустить». Если у дева два и больше рагпулла или после graduation не сожжена ликвидность, оценка ограничивается сверху.

## Запуск

```bash
npx serve .
# или просто откройте index.html в браузере
```

## Подключение реальных данных

Сейчас в `loadListings()` стоят демо-токены в формате Pons. Для продакшена эту функцию нужно заменить запросом к бэкенду-индексатору (контракт фабрики Pons в Robinhood Chain или API Pons). Бэкенд должен возвращать массив объектов такой формы:

```js
{
  id, ticker, name, emoji, hue, address, creator, chain: "Robinhood",
  graduated, progress, ageMin, mcap, holders, top10, dev, snipers,
  vol24, buys, sells, liq, devPrev, devRugs,
  socials: { x, tg, web }, lpBurned, pts: [/* 40 точек цены */], chg
}
```

## AI-обзор

Обзор запрашивается через `window.claude.use("sample")`. Это работает, когда страница опубликована как Claude-артефакт. Вне Claude используется алгоритмический обзор по тем же метрикам. Для своего хостинга замените вызов `sample(...)` в `runAI()` запросом к своему бэкенду с LLM: промпт и формат JSON-ответа уже есть в коде.

> Не является финансовой рекомендацией. Мемкоины крайне волатильны.
